# WCH PCI 和 PCIe 总线转串口与并口芯片Linux设备驱动程序

## 描述

本驱动程序支持 PCI 接口芯片 CH351/CH352/CH353/CH355/CH356/CH357/CH358/CH359 以及 PCIe 接口芯片 CH382/CH384。该驱动支持内核版本2.6.0及以上的Linux系统版本。

上述部分芯片型号已被系统自带的 `8250_pci` 和 `parport_serial` 驱动支持。您可以输入 `dmesg | grep ttyS` 来查找相关的 tty 设备，输入 `ls /dev/lp*` 来查找并口设备。

当使用本厂商驱动时，tty 设备将被命名为 `/dev/ttyWCH*`，而并口设备仍命名为 `/dev/lp*`。成功加载本驱动后，系统自带的 `8250_pci` 和 `parport_serial` 驱动会自动解绑。我们建议客户使用本驱动，因为它支持几乎所有的高级特性。

- 打开“终端 (Terminal)”
- 输入 `sudo sh install.sh` 使驱动程序永久生效
- 输入 `sudo sh uninstall.sh` 卸载驱动程序

您可以参考以下链接获取串口（UART）应用程序，您可以使用 gcc 进行编译，或使用 `cross-gcc` 进行交叉编译：https://github.com/WCHSoftGroup/tty_uart

## 注意事项

如果您正在使用如 CH384 + CH438 * n 这样的多串口卡来实现多串口功能，我们推荐使用以下硬件组合及专用 PID。当使用以下硬件方案时，芯片需要连接到 EEPROM 并烧录特定的配置文件。该文件可向WCH厂商获取。

- **PCIe 转 8 端口高速串口：** CH384[S0-S3] + CH438[S2-S5] | PID: 0x4808
- **PCIe 转 10 端口高速串口：** CH384[S0-S3] + CH438[S1-S6] | PID: 0x480A
- **PCIe 转 16 端口高速串口：** CH384[S0-S3] + CH438#1[S1-S7] + CH438#2[S1-S5] | PID: 0x4810
- **PCIe 转 20 端口串口：** CH384 + CH438#1[S0-S7] + CH438#2[S0-S7] | PID: 0x4814

如果用户在未注意到本说明的情况下，自行使用 CH384 和 CH438 的组合设计了多串口卡，在不进行硬件改版的情况下，临时解决方案如下：

您可以修改 `wch_devtable.c` 中（约第 3 行）定义的串口数量变量 `PCIE_UART_MAX`，将数字 **28** 修改为实际的串口数量。此方法要求硬件设计必须是 28 端口串口卡的修改版本，且主板 ID (board ID) 必须为 `1c00:4353`。

在本驱动中，默认使用 22.1184M 的频率来计算串口波特率。如果需要其他波特率，硬件需要使用其他频率的晶振，并修改 `wch_common.h` 中（约第 286 行）定义的晶振频率变量 `CRYSTAL_FREQ`。

通常，串口的内部参考时钟 (uartclk) 等于外部晶振频率的 1/12 或 2 倍。

**串口波特率 = uartclk / 16 / 16位波特率除数寄存器值**。

当该寄存器值等于 1 时，即可计算出该晶振支持的最大串口波特率。例如：

- 当选择 22.1184MHz 晶振时，波特率(最大) = 22.1184M * 2 / 16 / 1 = 2.7648Mbps。
- 当选择 64MHz 晶振时，波特率(最大) = 64M * 2 / 16 / 1 = 8Mbps。

如果您使用的是 RS485 串口卡，并且使用芯片的 DTR 引脚作为 RS485 收发指示开关，您可以通过修改 `wch_devtable.c` 中的 RS485 使能开关来进行切换。以基于 CH384 芯片制作的4通道 RS485 串口卡为例：

```
/* CH384_4S */
  {
     VENDOR_ID_WCH_PCIE,
     DEVICE_ID_WCH_CH384_4S,
     SUB_VENDOR_ID_WCH_PCIE,
     SUB_DEVICE_ID_WCH_CH384_4S,
     4,
     0,
     0xE9,
     0x00,
     0x00,
     0x00,
     "CH384_4S",
     BOARDFLAG_NONE,
     {
       { 's', 0, 0xC0, 8, -1, 0, 0, WCH_BOARD_CH384_4S,
        1 }, /* 1: 启用 DTR0 切换 RS485 方向控制, 0: 禁用 */
       { 's', 0, 0xC8, 8, -1, 0, 0, WCH_BOARD_CH384_4S,
        1 }, /* 1: 启用 DTR1 切换 RS485 方向控制, 0: 禁用 */
       { 's', 0, 0xD0, 8, -1, 0, 0, WCH_BOARD_CH384_4S,
        1 }, /* 1: 启用 DTR2 切换 RS485 方向控制, 0: 禁用 */
       { 's', 0, 0xD8, 8, -1, 0, 0, WCH_BOARD_CH384_4S,
        1 }, /* 1: 启用 DTR3 切换 RS485 方向控制, 0: 禁用 */
     },
  },
```
